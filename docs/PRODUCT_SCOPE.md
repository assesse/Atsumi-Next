# 제품 정의와 범위

## 제품 한 문장

Atsumi Next는 Hitomi 기반 갤러리를 빠르게 탐색하고, 사용자가 원하는 작품만 안정적으로 다운로드하며, 작품 및 페이지 중복을 사람이 검토 가능한 근거와 함께 관리하는 Windows 데스크톱 앱이다.

## 핵심 사용자 가치

1. 표지, 제목, 작가와 태그를 가까이 보며 빠르게 탐색한다.
2. 관련 작품을 상세 탭으로 연속 탐색하되 원래 탐색 문맥을 잃지 않는다.
3. 선택한 작품은 앱 종료나 네트워크 실패가 있어도 안정적으로 이어받는다.
4. 중복 가능성은 자동으로 후보화하지만 최종 삭제 결정은 사용자가 한다.
5. 즐겨찾기 작가의 새 작품을 명시적인 갱신 작업으로 찾는다.
6. 다운로드한 파일, 목록, 해시, 제외 기록이 서로 어긋나지 않는다.

## 제품 원칙

- **탐색 우선:** 첫 화면은 마케팅 화면이 아니라 실제 Explore 목록이다.
- **안정된 배치:** 선택, 진행률, 오류 표시가 콘텐츠 위치를 밀지 않는다.
- **상태 가시성:** 검색, 썸네일, 다운로드, 해시 작업이 진행 중인지 바로 보인다.
- **행동의 근접성:** 명령은 그 대상과 사용 시점 가까이에 둔다.
- **점진적 정보:** 카드에는 판단에 필요한 최소 정보, 상세과 검토 화면에는 전체 정보를 둔다.
- **사용자 판정 우선:** 중복 삭제와 내부 페이지 정리는 자동 확정하지 않는다.
- **복구 가능성:** 중단, 실패, 숨김, 삭제는 원인과 다음 행동을 가진다.
- **일관된 객체:** Explore, Auto Find, Downloads, Related에서 Gallery의 의미와 기본 동작이 같다.

## 주요 영역

### Explore

- Hitomi 전체 검색
- 최신 및 인기 기간 정렬
- 기본 포함과 숨김 태그
- 다중 언어 필터
- 검색 추천과 검색 기록
- 페이지 단위 탐색과 다음 페이지 선로딩

### Auto Find

- 즐겨찾기 작가의 최신 후보 명시적 갱신
- 다운로드 이력이 없으면 해당 작가의 전체 기간 후보 탐색
- 전체 및 작가별 그룹 보기
- 후보 일괄 다운로드

### Downloads

- 대기, 진행, 완료, 실패, 중단, 검토 필요 상태
- 자동 작업 시작과 전역 동시성 제어
- 전체 및 선택 다운로드
- 작가별 그룹과 탭 내부 검색
- 외부 뷰어 열기, 파일 삭제, 재시도
- 선택 대상의 내부 중복 검사

### Detail

- 여러 탭과 부모 옆 자식 삽입
- 전체 metadata와 즐겨찾기 표시
- 5개의 Related galleries
- 모든 페이지 lazy preview
- metadata 검색 이동과 페이지 확대

### Review

- 작품 중복 후보 비교
- E-Hentai 관계와 이미지 포함 근거
- 전체 일치 페이지쌍
- 부모 숨기기, 후보 숨기기, 연작 묶기, 묶음 풀기
- 다운로드 완료 앨범의 내부 유사 장면 블록 비교
- 남길 페이지 묶음 선택과 quarantine

## 첫 정식 완성 범위

첫 번째 통합 milestone은 다음 수직 흐름이다.

`Explore 검색 -> 상세 확인 -> 대기열 추가 -> 자동 다운로드 -> 진행 이벤트 -> 종료 후 복구 -> 완료 파일 열기`

이 흐름의 완료 조건:

- 검색 결과와 썸네일이 UI를 멈추지 않는다.
- 같은 갤러리를 두 번 queue해도 job은 하나다.
- 앱을 다운로드 중 강제 종료해도 재시작 후 상태가 복구된다.
- 완료 상태는 DB와 실제 파일 검증 후에만 성립한다.
- 오류는 구조화된 코드, 사용자 문구, 재시도 가능 여부를 가진다.
- Classic 데이터는 읽기 전용 import 복사본으로만 사용한다.

## 첫 milestone에서 제외

- ExHentai 전용 콘텐츠 확장
- 모바일 데이터 transfer
- `yt-dlp` 및 DNS 우회 sidecar
- 자동으로 파일을 영구 삭제하는 중복 판정
- Classic UI의 픽셀 단위 완전 복제
- 모든 고급 중복 알고리즘의 즉시 이식

제외는 폐기를 의미하지 않는다. 기반 흐름 안정화 이후 milestone에서 재검토한다.
